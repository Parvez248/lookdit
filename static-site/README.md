# LOOKDIT static site

Generated by `pnpm export:static` (scripts/export-static.mts). Do not edit these files by hand:
change the app, then export again.

Upload everything in this folder to your web host's public folder (for example `public_html`).
Each page is one HTML file with all of its CSS inside a `<style>` block. Fonts and images are
in `assets/`.

Pages (10): /, /about, /privacy, /services/digital-marketing, /services/seo, /services/web-apps, /work, /work/concepts/business-management-dashboard, /work/concepts/ecommerce-customer-experience, /work/concepts/healthcare-appointment-booking

## Before going live

- Contact form: **not connected.** It posts to the placeholder `https://formspree.io/f/YOUR_FORM_ID`. Create a form on a service such as Formspree and export again with `--form-action <its URL>`.
- Site URL: **not set.** Canonical URLs, sitemap.xml and JSON-LD were left out. Export again with `--site-url https://your-domain`.
